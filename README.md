# Fancy a Trip?

Static frontend for GitHub Pages, built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui (Base UI primitives).

## Development

```bash
pnpm install
pnpm dev
```

## Quality checks

```bash
pnpm lint
pnpm typecheck
pnpm build
```

The production output is the static `dist/` directory. No server runtime is used.

## Sidebar image generation

Sidebar filter images are generated by `scripts/generate-ui-filter-images.mjs`
through the local-only Pexels client. Store the credential in the ignored `.env`
file as `PEXELS_API_KEY` (copy `.env.example` on a new machine), then run:

```bash
pnpm images:generate-ui
```

The key is used only by the local script; the generated sidebar URLs are public
frontend data.

## Place Symbol photos

`Symbols` comes from Airtable as semicolon-separated text. `pnpm sync:airtable`
imports it alongside Country and Region. Every place photo is selected manually
from Pexels candidates; the application reads only
`src/data/place-symbol-images.generated.ts`, which contains place IDs, exact
Symbol names, and final image URLs.
Five user-selected Symbol names are held as record-ID overrides in
`scripts/import-airtable-places.mjs` until Airtable reflects them. The import
checks the source names before applying each override, so a future change is
reported instead of silently replacing it.

To review one missing pair:

```bash
pnpm images:prepare-symbol PLACE_ID 'exact Symbol'
```

The script runs landscape Pexels searches, downloads up to 30 previews, and
writes metadata plus an HTML review page under the ignored `.image-candidates/`
directory. Use two or three `--query 'English search'` arguments when a Symbol
needs more specific geography. Review the previews and Pexels metadata yourself.
Use `--page 2` or a later page when the first candidates are unsuitable.
Reject other locations and verify that the Symbol is visible. Then save a
reviewed candidate with:

```bash
pnpm images:select-symbol PLACE_ID 'exact Symbol' PHOTO_ID verified symbol-visible
```

Use `compatible` instead of `verified` only when location metadata does not
confirm the place and does not conflict. The selection command checks landscape
dimensions and duplicate photo IDs before writing. Existing selections persist
across runs. `pnpm images:validate-symbols` removes obsolete pairs and reports
missing Symbols, duplicate IDs, and URL errors.

## Deployment

The GitHub Actions workflow deploys the `main` branch to GitHub Pages. It takes the Pages base path from GitHub's `configure-pages` action so project Pages and custom domains receive the appropriate Vite `base` value.

## Adding shadcn/ui components

Use the locally installed official skill in `.agents/skills/shadcn` for substantial shadcn work. Add components with the current CLI, for example:

```bash
pnpm dlx shadcn@latest add button
```
